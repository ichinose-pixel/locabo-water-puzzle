# つなげて特典GET！水路パズル

LOCABO:Vの商品ページへ案内するゲームLPです。

## 公開

GitHub Pages: Settings → Pages → Deploy from a branch → main / (root) → Save。

公開URL: https://ichinose-pixel.github.io/locabo-water-puzzle/

## 体験

20秒の水路パズル → クリア特典 → 自動進行の仕組み説明 → 商品CTA。

時間内クリアでGOHAN2000を案内し、2,000円OFF（17,800円税込）。未クリア時は19,800円税込の導線。コードは注文画面で入力する方式です。

## ファイル

index.htmlにスタイル・スクリプト・画像を同梱した静的ページです。ビルドは不要です。

## 確認範囲

ゲーム処理・遷移・クーポン分岐・コピー処理を検証済み。実ブラウザの表示と注文画面のクーポン適用は未確認です。
